# InternHub

InternHub is a full-stack internship management system designed to manage interns, tasks, projects, attendance, work reports, and feedback in one place.

## Features

- Add, view, update, and delete intern records
- Create, assign, update, and delete tasks
- Create and manage projects
- Record and manage intern attendance
- Submit, view, update, and delete work reports
- Add and manage intern feedback
- REST API using Node.js and Express
- Database management using MySQL and Sequelize
- React.js frontend

## Modules

### Interns
Manage intern information such as:
- Name
- Email
- Phone
- Course
- Department
- Joining Date

### Tasks
Manage tasks assigned to interns, including:
- Task title
- Description
- Status
- Due date
- Intern ID
- Project ID

### Projects
Create and manage internship projects.

### Attendance
Record and manage intern attendance.

### Work Reports
Submit and manage work reports submitted by interns.

### Feedback
Add and manage performance feedback for interns.
